# Cinema Sales Analysis

## Dataset

This project uses the [Cinema Tickets dataset](https://www.kaggle.com/datasets/arashnic/cinema-ticket) from Kaggle.
The data is not included in this repository: download the CSV from Kaggle and place it in the `data/` folder to reproduce the analysis.

Domande di business:
1)Come si distribuiscono le vendite nel tempo? (finestra temporale limitata dal dataset
2)Quali sale generano più incassi e quanto è concentrato l'incasso
3)Quali sale si riempono di più e quali restano vuote
4)Il prezzo del biglietto,influenza il riempimento della sala?
5)Come calano le vendite di un film dopo la sua uscita
